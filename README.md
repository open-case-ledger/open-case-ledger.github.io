# open-case-ledger.github.io
Public cold-case research and case documentation

## Homepage list rule

Long public sections are automatically paginated after 20 entries. Keep newest material first. The homepage shows 20 items at a time with Newer / Older controls so the site remains usable as the ledger grows. Apply `data-page-size="20"` to any article container that should use this behavior; `site.js` handles the pagination automatically.
