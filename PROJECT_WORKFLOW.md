# Open Case Ledger Project Workflow

## Outbound email preflight

Before recommending, drafting, or sending any outreach email for a case:

1. Search the Open Case Ledger Gmail account for the proposed recipient email address and agency domain.
2. Search Gmail for the case name, victim name, and any known agency case number.
3. Review recent sent messages to the same agency to avoid sending multiple records requests in close succession unless there is a clear reason.
4. Check whether another Open Case Ledger case is already open with that agency or records unit.
5. If an active request already exists with that agency, prefer rotating to a different agency/case unless the new request is time-sensitive, clearly unrelated, or specifically requested.
6. Only after this preflight should a new outreach email be recommended or drafted.

## Case rotation preference

Prefer rotating across different agencies and cases rather than concentrating multiple consecutive requests on one agency. Favor email-based records routes when practical to reduce portal/password overhead.

## Preferred case profile

Priority goes to cases with a realistic identification or investigative advancement pathway, especially older pre-digital or pre-DNA-era cases, LGBTQ+/trans cases, and cases in Oregon, California, Colorado, Washington, or Nevada.
